## 1. Overview

### 1.1 Purpose

This specification defines a **local development Figma plugin** that reads structured JSON artifacts and programmatically generates:
- Design tokens (colors, spacing, typography, shadows, borders, motion)
- 33 reusable UI components with variants
- 3 dashboard screen layouts (Care Receiver, Caregiver, Admin)

The plugin automates ~50% of the Figma design production workflow, reducing human designer effort from "design a system from scratch" to "review and refine an auto-generated system."

### 1.2 Technology Stack

- **Language**: TypeScript
- **Runtime**: Figma Plugin API (sandbox + UI iframe architecture)
- **Build**: esbuild or webpack
- **Distribution**: Local development only (loaded via "Plugins → Development → Import plugin from manifest")

### 1.3 Input Artifacts

The plugin consumes 3 JSON files generated by agents:

1. `/docs/tiers/tier1/figma/tokens.json` — Design tokens in Figma Tokens Studio format
2. `/docs/tiers/tier1/figma/components.json` — 33 component schemas with variants, props, layers
3. `/docs/tiers/tier1/figma/screens/*.json` — Screen layouts that reference components and tokens

### 1.4 Key Constraints

- **One-time import tool**: Designed for initial Figma file creation, not continuous sync
- **Idempotent**: Running the plugin twice should update/replace existing nodes, not duplicate
- **Human review required**: Output is 80-90% complete; final visual polish by designer
- **No external dependencies**: Pure Figma Plugin API, no third-party services

## 4. Token Import Module

### 4.1 Token Types and Mapping

| Token Type | JSON Path | Figma API | Example |
|------------|-----------|-----------|---------|
| **Colors** | `global.colors.text.primary` | `figma.createPaintStyle()` | `#0f172a` → Text/Primary |
| **Typography** | `global.typography.nav-link` | `figma.createTextStyle()` | Font, size, weight, line-height |
| **Shadows** | `global.boxShadow.card-soft` | `figma.createEffectStyle()` | Drop shadow with blur/offset |
| **Spacing** | `global.spacing[1-14]` | `figma.variables.createVariable()` | Numeric values (4px, 8px, etc) |
| **Border Radius** | `global.borderRadius.sm` | `figma.variables.createVariable()` | Numeric values (12px, 18px, etc) |
| **Opacity** | `global.opacity.95` | `figma.variables.createVariable()` | 0.95 |
| **Duration** | `global.transitionDuration.ui` | `figma.variables.createVariable()` | 250ms |
| **Easing** | `global.transitionEasing.reveal` | Variable (string) | cubic-bezier(...) |

```typescript
// Example: Create color styles from tokens.json
function createColorStyles(colors: ColorTokens) {
  const collection = figma.variables.createVariableCollection('iCare Colors');

  // Flatten nested color object
  const flatColors = flattenTokens(colors); // { "text.primary": "#0f172a", ... }

  for (const [path, colorData] of Object.entries(flatColors)) {
    const style = figma.createPaintStyle();
    style.name = path.replace(/\./g, '/'); // "text.primary" → "text/primary"
    style.description = colorData.description || '';
    style.paints = [{
      type: 'SOLID',
      color: hexToRgb(colorData.value),
      opacity: extractOpacity(colorData.value) // Handle rgba()
    }];

    // Also create as variable for programmatic use
    const variable = figma.variables.createVariable(path, collection, 'COLOR');
    variable.setValueForMode(collection.modes[0].modeId, hexToRgb(colorData.value));
  }
}
```

### 4.6 Token Resolution Engine (Nested References)

```typescript
/**
 * Resolves token references like {fontSizes.base} to actual values.
 * Handles nested references (tokens referencing other tokens).
 */
class TokenResolver {
  private tokens: any;
  private cache = new Map<string, any>();

  constructor(tokensJSON: TokensJSON) {
    this.tokens = tokensJSON;
  }

  resolve(value: string | number): string | number {
    if (typeof value !== 'string') return value;
    if (!value.startsWith('{')) return value;

    // Extract path from {path.to.token}
    const path = value.slice(1, -1);

    if (this.cache.has(path)) {
      return this.cache.get(path);
    }

    // Navigate nested object
    const parts = path.split('.');
    let current = this.tokens;

    for (const part of parts) {
      current = current?.[part];
      if (current === undefined) {
        console.warn(`Token not found: ${path}`);
        return value; // Return original if not found
      }
    }

    // If result has .value, extract it
    const result = current?.value !== undefined ? current.value : current;

    // Recursively resolve if result is also a reference
    const resolved = this.resolve(result);
    this.cache.set(path, resolved);

    return resolved;
  }

  resolveAll(obj: any): any {
    if (typeof obj === 'string') return this.resolve(obj);
    if (typeof obj !== 'object' || obj === null) return obj;

    const resolved = Array.isArray(obj) ? [] : {};
    for (const [key, value] of Object.entries(obj)) {
      resolved[key] = this.resolveAll(value);
    }
    return resolved;
  }
}
```

### 5.2 Component Creation Flow

```typescript
async function generateComponent(schema: ComponentSchema, resolver: TokenResolver) {
  // Step 1: Create component frame
  const component = figma.createComponent();
  component.name = schema.name;
  component.resize(
    parseSize(schema.dimensions.width),
    parseSize(schema.dimensions.height)
  );

  // Step 2: Create layers recursively
  for (const layer of schema.layers) {
    const node = await createLayer(layer, component, resolver);
    component.appendChild(node);
  }

  // Step 3: Apply auto-layout if specified
  if (schema.layout?.type === 'vertical' || schema.layout?.type === 'horizontal') {
    component.layoutMode = schema.layout.type === 'vertical' ? 'VERTICAL' : 'HORIZONTAL';
    component.primaryAxisSizingMode = 'AUTO';
    component.counterAxisSizingMode = 'FIXED';
  }

  // Step 4: Create component properties
  for (const prop of schema.props) {
    createComponentProperty(component, prop);
  }

  // Step 5: Create variants if defined
  if (schema.variants && schema.variants.length > 0) {
    return createVariants(component, schema.variants);
  }

  return component;
}
```

### 5.3 Layer Creation Logic

```typescript
async function createLayer(
  layer: LayerDefinition,
  parent: BaseNode & ChildrenMixin,
  resolver: TokenResolver
): Promise<SceneNode> {
  let node: SceneNode;

  switch (layer.type) {
    case 'frame':
      node = figma.createFrame();
      node.name = layer.name;

      // Apply tokens
      if (layer.tokens) {
        applyTokensToFrame(node as FrameNode, layer.tokens, resolver);
      }

      // Create children recursively
      if (layer.children) {
        for (const child of layer.children) {
          const childNode = await createLayer(child, node as FrameNode, resolver);
          (node as FrameNode).appendChild(childNode);
        }
      }
      break;

    case 'rectangle':
      node = figma.createRectangle();
      node.name = layer.name;
      if (layer.tokens) {
        applyTokensToRectangle(node, layer.tokens, resolver);
      }
      break;

    case 'text':
      node = figma.createText();
      node.name = layer.name;

      // Load font before setting text
      const fontFamily = layer.tokens?.fontFamily || 'Inter';
      const fontWeight = layer.tokens?.fontWeight || '400';
      await figma.loadFontAsync({ family: fontFamily, style: mapWeight(fontWeight) });

      node.characters = layer.content || 'Text';
      if (layer.tokens) {
        applyTokensToText(node, layer.tokens, resolver);
      }
      break;

    case 'instance':
      // Reference to another component (created in earlier pass)
      const masterComponent = findComponentByName(layer.componentName);
      if (!masterComponent) {
        console.warn(`Component not found: ${layer.componentName}`);
        node = figma.createFrame(); // Placeholder
        node.name = `[Missing] ${layer.componentName}`;
      } else {
        node = masterComponent.createInstance();
      }
      break;

    case 'icon':
      // Placeholder for icons (designer will replace)
      node = figma.createRectangle();
      node.name = `[Icon] ${layer.name}`;
      node.resize(24, 24);
      node.fills = [{ type: 'SOLID', color: { r: 0.9, g: 0.9, b: 0.9 } }];
      break;
  }

  // Apply position and size
  if (layer.position) {
    node.x = parseSize(layer.position.x);
    node.y = parseSize(layer.position.y);
  }

  if (layer.size) {
    node.resize(parseSize(layer.size.width), parseSize(layer.size.height));
  }

  // Handle conditional visibility (stored as description for manual review)
  if (layer.visible) {
    node.setPluginData('visibilityCondition', layer.visible);
  }

  return node;
}
```

### 5.4 Token Application to Nodes

```typescript
function applyTokensToFrame(node: FrameNode, tokens: Record<string, string>, resolver: TokenResolver) {
  // Fill (background)
  if (tokens.fill) {
    const color = resolver.resolve(tokens.fill);
    node.fills = [{ type: 'SOLID', color: hexToRgb(color) }];
  }

  // Stroke (border)
  if (tokens.stroke) {
    const borderColor = resolver.resolve(tokens.stroke);
    node.strokes = [{ type: 'SOLID', color: hexToRgb(borderColor) }];
    node.strokeWeight = parseFloat(tokens.strokeWidth || '1');
  }

  // Border radius
  if (tokens.borderRadius) {
    const radius = parseFloat(resolver.resolve(tokens.borderRadius));
    node.cornerRadius = radius;
  }

  // Padding (auto-layout)
  if (tokens.paddingHorizontal || tokens.paddingVertical) {
    node.layoutMode = 'HORIZONTAL'; // Will be overridden if vertical
    node.paddingLeft = parseFloat(resolver.resolve(tokens.paddingHorizontal || '0'));
    node.paddingRight = parseFloat(resolver.resolve(tokens.paddingHorizontal || '0'));
    node.paddingTop = parseFloat(resolver.resolve(tokens.paddingVertical || '0'));
    node.paddingBottom = parseFloat(resolver.resolve(tokens.paddingVertical || '0'));
  }

  // Gap (auto-layout)
  if (tokens.gap) {
    node.itemSpacing = parseFloat(resolver.resolve(tokens.gap));
  }

  // Shadow
  if (tokens.boxShadow) {
    const shadowStyle = findEffectStyle(resolver.resolve(tokens.boxShadow));
    if (shadowStyle) {
      node.effectStyleId = shadowStyle.id;
    }
  }
}

function applyTokensToText(node: TextNode, tokens: Record<string, string>, resolver: TokenResolver) {
  // Font size
  if (tokens.fontSize) {
    node.fontSize = parseFloat(resolver.resolve(tokens.fontSize));
  }

  // Font weight (requires loading font)
  if (tokens.fontWeight) {
    const weight = resolver.resolve(tokens.fontWeight);
    // Already loaded in createLayer, just set
  }

  // Line height
  if (tokens.lineHeight) {
    const lh = parseFloat(resolver.resolve(tokens.lineHeight));
    node.lineHeight = { value: lh * 100, unit: 'PERCENT' };
  }

  // Letter spacing
  if (tokens.letterSpacing) {
    node.letterSpacing = {
      value: parseFloat(resolver.resolve(tokens.letterSpacing)),
      unit: 'PIXELS'
    };
  }

  // Fill (text color)
  if (tokens.fill) {
    const color = resolver.resolve(tokens.fill);
    node.fills = [{ type: 'SOLID', color: hexToRgb(color) }];
  }
}
```

### 5.5 Variant Generation

```typescript
function createVariants(baseComponent: ComponentNode, variants: VariantDefinition[]): ComponentSetNode {
  const components: ComponentNode[] = [baseComponent];

  // Clone base component for each variant
  for (let i = 1; i < variants.length; i++) {
    const clone = baseComponent.clone();
    clone.name = variants[i].name;
    // Apply variant-specific modifications (manual step, plugin creates structure)
    components.push(clone);
  }

  // Combine into component set
  const componentSet = figma.combineAsVariants(components, figma.currentPage);
  componentSet.name = baseComponent.name.split(' - ')[0]; // Remove variant suffix

  return componentSet;
}
```

### 5.6 Component Organization

```typescript
function organizeComponents(components: ComponentNode[]) {
  // Group by category: navigation, layout, form, status, etc.
  const categories = new Map<string, ComponentNode[]>();

  for (const comp of components) {
    const schema = findSchemaById(comp.name);
    const category = schema?.category || 'other';

    if (!categories.has(category)) {
      categories.set(category, []);
    }
    categories.get(category).push(comp);
  }

  // Create pages for each category
  for (const [category, comps] of categories) {
    const page = figma.createPage();
    page.name = `Components - ${capitalize(category)}`;

    // Layout components in grid
    let x = 0, y = 0;
    for (const comp of comps) {
      comp.x = x;
      comp.y = y;
      page.appendChild(comp);

      x += comp.width + 100; // 100px gap
      if (x > 2000) { // Wrap at 2000px
        x = 0;
        y += 400; // Next row
      }
    }
  }
}
```

```typescript
    padding: { top: number; right: number; bottom: number; left: number };
  };
  sections: ScreenSection[];
}

  columns?: number;

  position: { x: number | string; y: number | string };
  size: { width: string | number; height: string | number };

}
```

### 6.2 Screen Generation Flow

```typescript
async function generateScreen(schema: ScreenSchema, resolver: TokenResolver) {
  // Step 1: Create top-level frame
  const screenFrame = figma.createFrame();
  screenFrame.name = schema._metadata.screenName;
  screenFrame.resize(schema.frame.width, parseSize(schema.frame.height));

  const bgColor = resolver.resolve(schema.frame.fill);
  screenFrame.fills = [{ type: 'SOLID', color: hexToRgb(bgColor) }];

  // Step 2: Sort sections by order
  const sortedSections = schema.sections.sort((a, b) => a.order - b.order);

  let currentY = 0;

  // Step 3: Create each section
  for (const section of sortedSections) {
    const sectionNode = await createSection(section, resolver);

    // Position section
    sectionNode.x = 0;
    sectionNode.y = currentY;
    screenFrame.appendChild(sectionNode);

    currentY += sectionNode.height + parseFloat(resolver.resolve(section.gap || '0'));
  }

  // Step 4: Apply auto-layout to frame
  screenFrame.layoutMode = 'VERTICAL';
  screenFrame.primaryAxisSizingMode = 'AUTO';
  screenFrame.counterAxisSizingMode = 'FIXED';

  // Add to screens page
  let screensPage = figma.root.findOne(node => node.name === 'Screens') as PageNode;
  if (!screensPage) {
    screensPage = figma.createPage();
    screensPage.name = 'Screens';
  }
  screensPage.appendChild(screenFrame);

  return screenFrame;
}
```

### 6.3 Section Creation

```typescript
async function createSection(section: ScreenSection, resolver: TokenResolver): Promise<FrameNode> {
  let sectionNode: FrameNode;

  // If section references a component, instantiate it
  if (section.component) {
    const masterComponent = findComponentByName(section.component);
    if (!masterComponent) {
      console.warn(`Component not found: ${section.component}`);
      sectionNode = figma.createFrame();
      sectionNode.name = `[Missing] ${section.name}`;
    } else {
      const instance = masterComponent.createInstance();

      // Apply props to instance
      if (section.props) {
        applyPropsToInstance(instance, section.props);
      }

      // Wrap instance in frame for positioning
      sectionNode = figma.createFrame();
      sectionNode.appendChild(instance);
      sectionNode.resize(instance.width, instance.height);
      sectionNode.primaryAxisSizingMode = 'AUTO';
    }
  } else {
    // Section is a container with children
    sectionNode = figma.createFrame();
    sectionNode.name = section.name;

    // Apply layout
    if (section.layout === 'vertical') {
      sectionNode.layoutMode = 'VERTICAL';
    } else if (section.layout === 'horizontal-grid') {
      // Figma doesn't have native grid, use horizontal auto-layout with wrapping (manual)
      sectionNode.layoutMode = 'HORIZONTAL';
    }

    // Apply padding
    if (section.padding) {
      sectionNode.paddingLeft = parseFloat(resolver.resolve(section.padding.horizontal || '0'));
      sectionNode.paddingRight = parseFloat(resolver.resolve(section.padding.horizontal || '0'));
      sectionNode.paddingTop = parseFloat(resolver.resolve(section.padding.vertical || '0'));
      sectionNode.paddingBottom = parseFloat(resolver.resolve(section.padding.vertical || '0'));
    }

    // Apply gap
    if (section.gap) {
      sectionNode.itemSpacing = parseFloat(resolver.resolve(section.gap));
    }

    // Create children
    if (section.children) {
      for (const child of section.children) {
        const childNode = await createScreenElement(child, resolver);
        sectionNode.appendChild(childNode);
      }
    }
  }

  // Apply size
  if (section.size) {
    const width = section.size.width === 'fill' || section.size.width === '100%' ? 1440 : parseSize(section.size.width);
    const height = section.size.height === 'auto' ? 'AUTO' : parseSize(section.size.height);

    if (height !== 'AUTO') {
      sectionNode.resize(width, height);
    } else {
      sectionNode.resize(width, sectionNode.height); // Keep calculated height
      sectionNode.primaryAxisSizingMode = 'AUTO';
    }
  }

  // Handle conditional visibility
  if (section.conditional) {
    sectionNode.setPluginData('conditional', section.conditional);
    // Add note for designer
    sectionNode.name += ` [Conditional: ${section.conditional}]`;
  }

  return sectionNode;
}
```

### 6.4 Screen Element Creation

```typescript
async function createScreenElement(element: ScreenElement, resolver: TokenResolver): Promise<SceneNode> {
  // Handle repeating elements (data iteration)
  if (element.repeat) {
    const container = figma.createFrame();
    container.name = `${element.component} (repeated)`;
    container.layoutMode = 'VERTICAL';
    container.itemSpacing = parseFloat(resolver.resolve(element.gap || '16'));

    // Create placeholder instances (designer will replace with real data)
    const count = element.maxVisible || 3;
    for (let i = 0; i < count; i++) {
      const instance = await createComponentInstance(element.component, element.variant);
      if (instance) {
        container.appendChild(instance);
      }
    }

    return container;
  }

  // Single component instance
  if (element.component === 'text') {
    const textNode = figma.createText();
    await figma.loadFontAsync({ family: 'Inter', style: 'Regular' });
    textNode.characters = element.content || 'Text';

    if (element.tokens) {
      applyTokensToText(textNode, element.tokens, resolver);
    }

    return textNode;
  }

  // Component instance
  const instance = await createComponentInstance(element.component, element.variant);

  if (instance && element.props) {
    applyPropsToInstance(instance, element.props);
  }

  return instance || figma.createFrame(); // Fallback
}

async function createComponentInstance(componentName: string, variant?: string): Promise<InstanceNode | null> {
  const masterComponent = findComponentByName(componentName, variant);
  if (!masterComponent) {
    console.warn(`Component not found: ${componentName} (variant: ${variant})`);
    return null;
  }

  return masterComponent.createInstance();
}
```

### 6.5 Component Property Application

```typescript
function applyPropsToInstance(instance: InstanceNode, props: Record<string, any>) {
  // Figma component properties API
  for (const [propName, propValue] of Object.entries(props)) {
    try {
      // Text properties
      if (typeof propValue === 'string') {
        instance.setProperties({ [propName]: propValue });
      }

      // Boolean properties
      if (typeof propValue === 'boolean') {
        instance.setProperties({ [propName]: propValue });
      }

      // Instance swap properties
      if (propValue.startsWith('component:')) {
        const targetComponent = findComponentByName(propValue.replace('component:', ''));
        if (targetComponent) {
          instance.setProperties({ [propName]: targetComponent });
        }
      }
    } catch (error) {
      console.warn(`Failed to apply property ${propName}:`, error);
    }
  }
}
```

## 8. Error Handling

### 8.1 Error Types and Responses

| Error Type | Detection | Response |
|------------|-----------|----------|
| **Invalid JSON syntax** | Try/catch on `JSON.parse()` | Show error in UI, block import |
| **Missing required fields** | Schema validation | Show specific missing fields |
| **Token not found** | Resolution fails | Warn in console, use fallback color |
| **Component not found** | `findComponentByName()` returns null | Create placeholder frame with note |
| **Figma API error** | API throws exception | Log error, continue with next item |
| **Font not available** | `loadFontAsync()` fails | Fall back to Inter Regular |
| **Circular token reference** | Recursion depth limit | Break cycle, log error |

### 8.2 Error Reporting to UI

```typescript
function reportError(errorType: string, details: string) {
  figma.ui.postMessage({
    type: 'error',
    payload: {
      errorType,
      message: details,
      timestamp: new Date().toISOString()
    }
  });
}

// Usage
try {
  createColorStyles(tokens.global.colors);
} catch (error) {

}
```

- **Performance**: Creating 100+ nodes at once may cause UI lag; use progress reporting and batch operations
- **Undo History**: Plugin operations create single undo step; user cannot partially undo import
