# Data Protection Impact Assessment (DPIA)

> **PLACEHOLDER** - Required by GDPR before processing personal data. Blocked by GD-02.

## Status

**BLOCKED** - Requires DPO or legal consultant engagement.

## Purpose

This DPIA assesses the risks to individuals' rights and freedoms from personal data processing in the UK elderly care marketplace.

## Scope

- Care receiver personal data (health conditions, care needs)
- Caregiver personal data (identity, qualifications, DBS)
- Family member data
- Payment and financial data
- Communications and messaging data

## Required Sections

1. Description of Processing
2. Necessity and Proportionality Assessment
3. Risk Assessment
4. Mitigation Measures
5. Sign-off
