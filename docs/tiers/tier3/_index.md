# Tier 3: Enhanced (Condition-Specific Matching)

**Timeline**: Months 12-18 (Triggered by Tier 2 success metrics)
**Status**: FUTURE
**Investment**: 80,000-120,000 GBP (cumulative)

---

## Overview

Tier 3 enables condition-specific matching and advanced care services including live-in care. This tier requires processing special category health data with explicit consent.

### Key Characteristics

- **Services**: All Tier 2 + live-in care, dementia-specific care, end-of-life support
- **Data**: Special category health data with explicit consent
- **Verification**: All Tier 2 + condition-specific training
- **CQC**: Still NOT required (monitor guidance)

## New Features at Tier 3

### Care Receiver Features
- Medical condition profile (explicit consent)
- Condition-specific caregiver matching
- Risk assessment capture
- Care complexity indication
- Live-in care bookings
- Emergency information storage

### Caregiver Features
- Medical condition experience profile
- Condition-specific training verification
- Live-in care availability
- Clinical safety logging

### Admin Features
- Clinical safety monitoring dashboard
- Condition-specific safeguarding protocols
- Live-in care DoLS guidance workflow
- SAB liaison tools

### Clinical Safety Features
- Medication prompting logging
- Falls and injury reporting
- Behavioral change flags
- Emergency escalation workflows
