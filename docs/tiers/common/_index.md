## Key Principles (From Marketplace Spec)

These apply at ALL tiers:

1. **Introduction Agency Model** - Platform introduces, doesn't employ
2. **Safety First** - Safeguarding is never compromised
3. **Regulatory Compliance** - Legal compliance at every tier
4. **Progressive Disclosure** - Features unlock with compliance
5. **Trust Architecture** - Verification builds trust incrementally
