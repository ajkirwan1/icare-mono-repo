## Keyword Research Methodology

### Approach

Keywords were selected based on:
- **Relevance** - Direct alignment with page content and user intent
- **Search Volume** - Estimated monthly searches in UK
- **Competition** - Difficulty to rank for the keyword
- **Commercial Intent** - Likelihood to convert to waitlist signup
- **Long-tail Variations** - Specific phrases users actually search

### Search Intent Classification

- **Informational** - User seeking information ("what is companion care")
- **Navigational** - User looking for specific brand/service ("icare website")
- **Commercial** - User researching options ("best companion care UK")
- **Transactional** - User ready to take action ("hire companion carer")

### Difficulty Ratings

- **Low** - Easier to rank, less competition (newer/niche terms)
- **Medium** - Moderate competition, established terms
- **High** - Highly competitive, requires significant SEO effort

## Keyword Optimization Recommendations

### On-Page SEO Best Practices

1. **Title Tag Optimization**
   - Include primary keyword near beginning
   - Keep under 60 characters
   - Include brand name ("iCare") at end
   - Make compelling for click-through

2. **Meta Description Optimization**
   - Include primary + 1-2 secondary keywords
   - Keep under 155 characters
   - Include call-to-action
   - Make engaging and descriptive

3. **H1 Optimization**
   - One H1 per page
   - Include primary keyword naturally
   - Can be emotional/compelling (not just keyword-stuffed)

4. **H2/H3 Optimization**
   - Include secondary keywords in H2s
   - Use question format for FAQ-style content
   - Create logical content hierarchy

5. **Keyword Density**
   - Primary keyword: 4-6 occurrences (1-2% density)
   - Secondary keywords: 2-3 occurrences each
   - Long-tail: Use naturally in sentences
   - Avoid keyword stuffing (sounds unnatural)

6. **LSI Keywords (Latent Semantic Indexing)**
   - Use related terms and synonyms
   - Example: "companionship" → "company", "companion", "time together"
   - Google understands semantic relationships

### Technical SEO Requirements

1. **URL Structure**
   - Include primary keyword in URL slug
   - Use hyphens (not underscores)
   - Keep short and descriptive
   - Example: `/care-guidance/elderly-loneliness` ✅
   - Not: `/care-guidance/article-1` ❌

2. **Image Alt Text**
   - Include keywords where relevant
   - Describe image content naturally
   - Don't keyword stuff alt text

3. **Internal Linking**
   - Link to related pages using keyword anchor text
   - Example: "Learn about our [safety commitment]" → /safety
   - Build topic clusters (hub and spoke model)

4. **Schema.org Markup**
   - Article schema for blog posts
   - FAQPage schema for FAQ page
   - Organization schema globally
   - Helps search engines understand content

### Content Strategy

1. **Topic Clusters**
   - **Pillar Page**: Care Guidance Hub
   - **Cluster 1**: Elderly loneliness (problem awareness)
   - **Cluster 2**: Signs parent needs help (early stage)
   - **Cluster 3**: Starting as carer (caregiver journey)
   - Link all cluster content back to pillar page

2. **Search Intent Matching**
   - Informational → Long-form articles (1,500+ words)
   - Commercial → Service pages with CTAs
   - Transactional → Clear action pages (How It Works)
   - Navigational → Simple, functional pages (Contact)

3. **Competitive Differentiation**
   - Target "UK" specifically (geographic modifier)
   - Focus on "companionship" (not generic "care")
   - Emphasize "trusted", "verified", "safe" (trust signals)
   - Position as "platform" (not agency)

4. **Long-Tail Strategy**
   - 70% of searches are long-tail
   - Easier to rank for (less competition)
   - Higher conversion (specific intent)
   - Target in body copy, not just headings

### Measurement & Iteration

1. **Track Rankings**
   - Monitor primary keyword rankings monthly
   - Use Google Search Console
   - Track position changes over time

2. **Analyze Traffic**
   - Which keywords drive traffic
   - Which pages rank highest
   - Which queries have high bounce rate (content gap)

3. **Optimize Underperformers**
   - Pages ranking 11-20 (page 2) → optimize to page 1
   - Add more content to thin pages
   - Improve internal linking to key pages

4. **Update Regularly**
   - Refresh statistics annually
   - Update articles with new information
   - Add new sections based on query trends
