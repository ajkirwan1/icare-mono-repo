# Tier 1: Minimal (Companionship MVP)

**Timeline**: Months 1-6
**Status**: ACTIVE - Current Development Focus
**Investment**: 15,000-25,000 GBP

---

## Overview

Tier 1 represents the minimum viable product for market entry, focusing on companionship services only. This tier validates product-market fit with the lowest possible compliance burden and investment risk.

### Key Characteristics

- **Services**: Companionship, light housework, shopping, meal preparation
- **Data**: Standard personal data only (no special category)
- **Verification**: ID, right to work, phone, email (DBS voluntary)
- **CQC**: NOT required (Introduction Agency model)

## Tier 1 Feature Summary

### Care Receiver Features
- Account registration (basic profile)
- Caregiver search by location/availability
- Filter by service type (companionship only)
- View caregiver profiles
- Request bookings
- In-app messaging
- Payment processing (escrow)
- Reviews and ratings

### Caregiver Features
- Professional profile creation
- Service type selection
- Availability calendar
- Booking management
- Earnings dashboard
- Basic verification (ID, right to work)

### Admin Features
- User management
- Basic caregiver verification
- Booking oversight
- Dispute resolution
- Safeguarding reporting
