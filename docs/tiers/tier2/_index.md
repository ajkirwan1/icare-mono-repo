# Tier 2: Standard (Personal Care)

**Timeline**: Months 6-12 (Triggered by Tier 1 success metrics)
**Status**: PLANNED
**Investment**: 40,000-60,000 GBP (cumulative)

---

## Overview

Tier 2 enables personal care services with appropriate verification and compliance. This tier is triggered when Tier 1 success metrics are achieved and validates the expanded marketplace model.

### Key Characteristics

- **Services**: All Tier 1 + personal care (washing, dressing, toileting), mobility assistance, medication prompting
- **Data**: Standard + skill requirements (potentially inferring health)
- **Verification**: Mandatory DBS, qualifications, insurance
- **CQC**: Still NOT required

## New Features at Tier 2

### Care Receiver Features
- Personal care service requests
- Care skill requirement specification
- Filter caregivers by verified skills
- View qualifications and DBS status
- Enhanced booking with care needs summary

### Caregiver Features
- Personal care services enabled
- Care skills profile (mandatory)
- Qualification uploads and verification
- DBS submission and verification
- Insurance upload and verification

### Admin Features
- DBS verification workflow
- Qualification verification process
- Insurance verification and expiry tracking
- Enhanced safeguarding reporting
